# False Positive and False Negative

A false positive is a legitimate transaction wrongly flagged as fraud (a false decline); a false negative is fraud that slipped through undetected — the two 'wrong' outcomes, each with different costs.

## Key Points

- False positives cost customer trust and lost revenue (Section 12)
- False negatives cost direct fraud loss (Section 12)
- Reducing one typically increases the other — the core threshold tradeoff
