# Fraud vs Default

Default is a legitimate borrower failing to repay a debt they genuinely intended (at least initially) to repay; fraud involves deception from the start.

## Key Points

- Default is a credit-risk problem; fraud is a security/deception problem
- Confusing the two corrupts labels — a defaulted-but-legitimate loan is NOT fraud
- Some fraud (first-party fraud) deliberately mimics default to hide intent
