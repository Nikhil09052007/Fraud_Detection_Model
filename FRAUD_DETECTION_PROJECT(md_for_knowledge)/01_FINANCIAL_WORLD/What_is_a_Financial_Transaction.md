# What is a Financial Transaction?

A financial transaction is an event where value moves from one party to another — a purchase, transfer, withdrawal, or payment. Every transaction has a payer, a payee, an amount, and a timestamp at minimum.

## Key Points

- Transactions are the atomic unit of financial data
- Each transaction can be legitimate or fraudulent — this label is what fraud models try to predict
- Transactions carry rich metadata: device, location, merchant, payment method, time
